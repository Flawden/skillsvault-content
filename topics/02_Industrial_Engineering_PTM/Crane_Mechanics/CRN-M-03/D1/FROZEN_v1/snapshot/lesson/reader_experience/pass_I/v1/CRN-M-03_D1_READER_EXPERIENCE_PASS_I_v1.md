# Findings and corrections

## RX-01 — Too many correct guards competed for working memory
**Severity:** HIGH

Added a four-question memory card:

```text
WHAT OBJECT?
→ WHERE DOES FORCE GO?
→ WHAT HOLDS THE LOAD?
→ WHAT AM I ENTITLED TO CLAIM?
```

The last question groups acceptance, applicability and authority guards under one evidence-status discipline.

## RX-02 — The load-path algorithm had no immediate worked representation
**Severity:** HIGH

Added one deliberately non-numeric micro-case after Step 5. It demonstrates system boundary, load path, role assignment and bounded conclusion while explicitly refusing compatibility/acceptance claims.

## RX-03 — Holding-principle families were prose-heavy before the learner saw the classifier
**Severity:** MEDIUM

Added a compact holding-principle router before Sections 7.1–7.6. It is explicitly a question map, **not a pre-use checklist**.

## RX-04 — Source roles looked like a list of standards to memorize
**Severity:** HIGH

Added a source router that starts from the technical question and exact object, then selects source role and exact applicability. No source hierarchy or authority was changed.

## RX-05 — Eight novice errors repeated many Red-Team guards as isolated negatives
**Severity:** MEDIUM

Grouped them under four evidence-status promotions: appearance→compatibility, observation/history→acceptance/validation, category→exact applicability, educational conclusion→equipment authority.

## RX-06 — STOP semantics were correct but cognitively dense
**Severity:** HIGH

Added a compact STOP-card:

```text
STOP UNSUPPORTED INFERENCE
→ NAME THE MISSING EVIDENCE
→ REQUEST EXACT DEVICE / SOURCE / OEM DATA
→ HAND OFF TO APPLICABLE PROCESS
```

The card explicitly preserves `SkillsVault STOP ≠ equipment-operation authority`.

## RX-07 — The lesson ended with a mental map but no retrieval test
**Severity:** MEDIUM

Added a seven-question retrieval checkpoint. It is not formal Practice and contains no answer key; it simply checks whether the learner can reconstruct the D1 model from memory.
