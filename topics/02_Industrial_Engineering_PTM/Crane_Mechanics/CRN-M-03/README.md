## Current depth

`D1 — ACTIVE / CONTENT KICKOFF COMPLETE v1`.

D1 establishes a beginner mental model for:

- crane-integral hook suspensions / hook blocks versus detachable below-hook attachments;
- generic hook nomenclature and load-path anatomy;
- hook seating/alignment and qualitative eccentric/side/tip-load awareness without numeric limits;
- latch/keeper role separation;
- common load-gripping principles: positive engagement, clamps/grips, C-hooks/forks/beams, magnets, vacuum, grabs/grab buckets;
- source-scope awareness: ISO 17096 covers several attachment families but explicitly excludes grabs/grab buckets;
- documentation/OEM escalation before any numeric, inspection-acceptance, repair or operational-permission claim.

D1 Source Gate = `PASS WITH CLAIM LIMITS`.

Current source anchors:

- ISO 4306-1:2026 — crane vocabulary/components;
- ISO 1837:2003 — lifting-hook nomenclature;
- ISO 17440:2014 — formal forged-hook proof scope boundary, not a universal hook-block rulebook;
- ISO 17096:2015 — several non-fixed load-lifting attachment categories plus explicit grab/grab-bucket exclusions;
- ФНП ПС №461, current edition 16.04.2026 — Russian regulatory/authority boundary;
- passport/OEM/device documentation — mandatory for actual equipment/device-specific decisions.
