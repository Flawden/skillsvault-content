# CRN-M-01 / D4 Verification Rubric v1 — Alignment

## ER coverage

All ER-01…ER-12 have explicit 0–4 descriptors.

## Verification architecture

- known case;
- unseen transfer case;
- adversarial challenge.

## Non-compensable safety/validity layer

Blocking failures:
- BF-01 Invented Critical Input
- BF-02 Safety Delay
- BF-03 Authority Creep
- BF-04 False Applicability
- BF-05 Unsupported Precision
- BF-06 Signal-to-Cause Shortcut

## Mandatory D4 core

For `D4 VERIFIED`:
- no BF;
- total 39–44 or higher;
- ER-12 >= 3;
- mandatory core dimensions >= 3;
- unseen case completed.

## Transfer design

Unseen scenario reverses Practice F:
- wheel is new;
- chain is old;
- elongation looks acceptable;
- local contact evidence remains;
- pair compatibility is incomplete.

This tests transfer rather than memory.
