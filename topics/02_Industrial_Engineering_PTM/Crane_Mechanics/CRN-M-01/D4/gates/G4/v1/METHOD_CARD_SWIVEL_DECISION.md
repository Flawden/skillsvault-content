# D4 Method Card
# Решение по вертлюгу

## 1. Разделить цель

### Монтаж
Нужно предотвратить перенос twist / дать монтажную развязку?

### Эксплуатация
Вертлюг остаётся в рабочей системе под нагрузкой?

Это разные решения.

---

# 2. Идентифицировать канат

Нужны:
- точная конструкция;
- производитель;
- rotational designation / category if given;
- инструкция производителя.

---

# 3. Идентифицировать ПС

- руководство;
- схема;
- крепление;
- штатный / нештатный вертлюг;
- ограничения.

---

# 4. Запрещённая логика

```text
крюк вращается
→ поставить вертлюг
```

и:

```text
вертлюг опасен
→ убрать вертлюг
```

без source review.
