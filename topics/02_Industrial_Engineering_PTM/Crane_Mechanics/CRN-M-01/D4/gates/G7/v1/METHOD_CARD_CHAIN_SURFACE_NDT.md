# D4 Method Card
# Поверхностная трещина цепи: выбор специализированного метода

## Вопрос

Есть подозрение на трещину звена.

## Метод A — магнитопорошковый

Подходит по общему принципу, если:
- материал ферромагнитный;
- ожидается поверхностная / близкая к поверхности несплошность;
- применима утверждённая процедура.

## Метод B — проникающий

Может быть полезен, если:
- дефект открыт на поверхность;
- поверхность и материал пригодны;
- применима процедура.

## Критически

Ни один общий стандарт метода сам по себе не говорит:

> «это звено допустимо».

Нужен:
- product/OEM acceptance criterion;
- применимая эксплуатационная рамка;
- уполномоченная оценка.

## SkillsVault output

Учащийся должен уметь:
- выбрать класс метода;
- объяснить почему;
- назвать ограничения;
- потребовать правильный acceptance source.

Не должен:
- самостоятельно назначать режим НК;
- сертифицировать результат.
