# D4 Method Card
# Выбор уровня механической модели

## Вопрос

Какую модель использовать для конкретной задачи по канату?

---

# 1. Сначала определить требуемый выход

Пример:

```text
сравнить две геометрии
```

не требует той же модели, что:

```text
оценить остаточный ресурс
```

---

# 2. Выбрать минимальный уровень

- M0 — геометрия / наблюдение
- M1 — упрощённая физика
- M2 — источникная инженерная модель
- M3 — локальная / численная
- M4 — валидированная ресурсная

---

# 3. Проверить входы

Если модель требует:
- коэффициент трения;
- геометрию проволок;
- свойства контакта;

а их нет,

нельзя просто подставить «типичное значение» без отдельного основания.

---

# 4. Проверить sensitivity

Если неизвестный вход слабо влияет:
- модель может оставаться полезной.

Если сильно:
- вывод должен быть ограничен;
- нужен measurement / source.

---

# 5. Проверить validation

Главный вопрос:

> validation похожа на наш объект по конструкции, режиму и критерию отказа?

---

# 6. Выход

- MODEL SUFFICIENT
- MODEL SUFFICIENT FOR COMPARISON ONLY
- MODEL INPUT-LIMITED
- MODEL OUT OF SCOPE
- HIGHER METHOD REQUIRED
- SPECIALIST HANDOFF REQUIRED
