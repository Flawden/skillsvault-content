# 1. Главная экспертная ошибка

Запрещённая логика:

```text
диаметр совпал
+
разрывное усилие не меньше
=
канат подходит
```

Даже совпадение этих двух характеристик не доказывает системную совместимость.

Экспертная модель:

```text
НАЗНАЧЕНИЕ КАНАТА
+
ПРИМЕНИМАЯ НОРМАТИВНАЯ РАМКА
+
КОНСТРУКЦИЯ КАНАТА
+
ПРОЧНОСТНАЯ ХАРАКТЕРИСТИКА
+
ГЕОМЕТРИЯ БАРАБАНА И БЛОКОВ
+
ТИП НАВИВКИ
+
ЗАПАСОВКА
+
КОНЦЕВЫЕ УСЛОВИЯ
+
ВРАЩАТЕЛЬНОЕ ПОВЕДЕНИЕ
+
РАДИАЛЬНАЯ / СТРУКТУРНАЯ УСТОЙЧИВОСТЬ
+
```

# 2. Что реально устанавливают ключевые источники

## ISO 16625:2025

Текущая международная редакция предназначена для выбора стальных канатов кранов и талей.

Публичная область стандарта подтверждает, что в проверку выбора включаются:

- критерии выбора каната;
- подтверждение расчётной состоятельности;
- геометрия канатного привода;
- геометрия барабанов;
- геометрия блоков.

Следовательно:

> канат нельзя корректно выбирать изолированно от канатной системы.

## ГОСТ 33710-2015

Действующий российский стандарт устанавливает критерии выбора канатов и минимальные коэффициенты запаса прочности `Zp` в зависимости, в частности, от:

- назначения;
- режима работы механизма;
- типа каната;
- типа барабана;

и связывает их с определением минимального разрывного усилия.

### Guard

Точные таблицы, коэффициенты и формулы стандарта в D4-G2 не воспроизводятся без подтверждённого текста применимой редакции.

# 3. Три разных вопроса, которые нельзя смешивать

## Вопрос A — «Это тот же самый канат?»

Это идентификация.

Проверяются:
- изготовитель;
- продукт;
- конструкция;
- обозначение;
- диаметр;
- направление и вид свивки;
- сердечник;
- класс прочности;
- сертификат.

## Вопрос B — «Этот канат технически совместим с существующей системой?»

Это compatibility review.

Проверяются:
- барабан;
- блоки;
- ручьи;
- многослойность;
- углы подхода;
- запасовка;
- вращательная задача;
- концевое условие;
- рабочая среда;
- режим работы;
- OEM-ограничения.

## Вопрос C — «Можно ли официально изменить проект и принять этот канат как новый выбор?»

Это уже design / approval question.

D4 может:
- проверить исходные данные;
- разобрать метод;
- выявить риски;
- выполнить источникно допустимый check;
- подготовить review.

Но D4 не присваивает человеку полномочие проектировщика или изготовителя.

# 4. Паспорт совместимости каната

Для экспертного review канат должен описываться не одним диаметром, а вектором характеристик.

## 4.1. Идентичность продукта

```text
manufacturer
product / construction
nominal diameter
actual / measured diameter where relevant
rope grade / strength designation
minimum breaking force from certificate
core
strand architecture
lay type
lay direction
rotation behaviour class / manufacturer designation
surface / coating
lubrication state / requirement
certificate / batch
```

Не все поля всегда обязательны.

Но эксперт должен знать, **какие из них могут быть критичны в данном механизме**.

# 6. Почему одинаковый диаметр не означает одинаковое поведение

Два каната одного номинального диаметра могут различаться:

- числом и архитектурой прядей;
- сердечником;
- уплотнением;
- распределением металла;
- радиальной устойчивостью;
- структурной устойчивостью;
- изгибной гибкостью;
- сопротивлением абразивному воздействию;
- вращательным откликом;
- допустимостью работы с вертлюгом;
- поведением на многослойном барабане.

Следовательно:

```text
d1 = d2
```

не означает:

```text
mechanical response 1 = mechanical response 2
```

---

# 7. Почему одинаковое минимальное разрывное усилие не означает одинаковую пригодность

Минимальное разрывное усилие отвечает на прочностный вопрос.

Оно не описывает полностью:

- изгибную долговечность;
- контактную стойкость;
- сопротивление смятию;
- радиальную устойчивость;
- крутильное поведение;
- многослойную укладку;
- видимость / характер повреждений;
- совместимость с конкретным барабаном и блоками.

Поэтому:

```text
MBF sufficient
```

может быть необходимым условием в конкретной проверке,

но не является универсальным достаточным условием совместимости.

---

# 8. Конструкция каната — не «лучше / хуже», а набор trade-offs

D4 запрещает рейтинг:

```text
КАНАТ A
>
КАНАТ B
```

без контекста.

Правильная форма:

```text
КОНСТРУКЦИЯ A
лучше по свойству X
в режиме Y
при ограничении Z

НО
имеет trade-off по свойству Q.
```

Типичные оси trade-off:

- гибкость;
- изгибная долговечность;
- наружный износ;
- внутреннее повреждение;
- радиальная устойчивость;
- смятие;
- вращательная устойчивость;
- контролепригодность;
- поведение при многослойной навивке.

---

# 9. OEM-доказательство: почему нужны product-specific данные

Текущая техническая документация verope показывает на конкретных специальных канатах, что:

- радиальная устойчивость зависит от конструкции и натяжения;
- недостаточная радиальная устойчивость может быть проблемой для многослойной навивки;
- уменьшение диаметра под нагрузкой важно для многослойного барабана;
- разные конкретные конструкции имеют разные указания по работе с вертлюгом;
- геометрия крана и система барабана являются факторами выбора.

### Правильный вывод

Это подтверждает **класс переменных**, которые эксперт обязан проверять.

### Неправильный вывод

Нельзя переносить:
- конкретное правило verope;
- конкретный продукт;
- конкретное ограничение вертлюга;
- конкретное число производителя

на любой другой канат.

# 10. Четыре уровня compatibility review

## C0 — Геометрическое совпадение

Проверено:
- номинальный диаметр.

Этого почти никогда недостаточно.

## C1 — Документальная идентификация

Дополнительно:
- конструкция;
- прочностная характеристика;
- сертификат;
- свивка;
- назначение.

Это всё ещё не полная системная совместимость.

## C2 — Системная совместимость

Дополнительно:
- барабан;
- блоки;
- ручьи;
- запасовка;
- навивка;
- вращательное поведение;
- концевые условия;
- среда;
- duty.

Это полноценный инженерный compatibility review.

## C3 — Источникно подтверждённый design check

Дополнительно:
- применимый расчётный метод;
- исходные данные;
- коэффициенты;
- редакция;
- воспроизводимый расчёт;
- область применения;
- sensitivity / uncertainty.

D4 может учить выполнить такой check только там, где метод реально доступен и подтверждён.

## C4 — Design approval

Официальное изменение / утверждение проектного решения.

Это не учебный уровень SkillsVault.

# 13. Compatibility matrix

| Проверка | Совпадение обязательно? | Может быть другим? | Кто задаёт допустимость? |
|---|---|---|---|
| Диаметр | зависит от проекта / документа | иногда | стандарт + OEM + система |
| Конструкция | не обязана быть идентичной | да | design/OEM review |
| Разрывное усилие | должно удовлетворять применимой проверке | да | применимый расчёт |
| Свивка | system-dependent | да/нет | OEM / схема |
| Направление свивки | system-dependent | да/нет | OEM / система |
| Вращательная характеристика | critical for some duties | да | OEM / method |
| Сердечник | может отличаться | да | design review |
| Многослойная пригодность | critical if multilayer | — | OEM / source-bound review |
| Работа с вертлюгом | construction-specific | — | OEM / applicable source |
| Радиальная устойчивость | может быть critical | — | product / method data |
| Покрытие / смазка | environment-dependent | да | environment + OEM |

Таблица — карта вопросов, а не универсальный норматив.
