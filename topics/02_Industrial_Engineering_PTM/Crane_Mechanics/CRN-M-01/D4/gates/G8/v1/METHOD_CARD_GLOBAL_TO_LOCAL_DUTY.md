# D4 Method Card
# Глобальный режим крана → локальная история каната

## Вопрос

Можно ли использовать статистику работы крана для объяснения повреждения конкретного участка каната?

## Шаг 1 — глобальный слой

Собрать:
- классификацию;
- число рабочих циклов;
- нагрузочный спектр;
- перемещения;
- данные регистратора.

## Шаг 2 — геометрия канатного привода

- запасовка;
- блоки;
- барабан;
- слои;
- переходы;
- высоты.

## Шаг 3 — локальная координата

Для повреждённого участка определить:
- где он находится на барабане;
- через какие блоки проходит;
- когда нагружается;
- где изгибается;
- где контактирует.

## Шаг 4 — преобразование событий

Не:

```text
100 000 циклов крана
=
100 000 циклов каната
```

А:

```text
рабочий цикл
→ движения механизма
→ проходы участка
→ изгибы / контакты / переходы
```

## Выход

- LOCAL HISTORY SUPPORTED
- LOCAL HISTORY PARTIALLY RECONSTRUCTED
- GLOBAL DUTY ONLY
- DATA INSUFFICIENT
- SOURCE-BOUND MODEL REQUIRED
