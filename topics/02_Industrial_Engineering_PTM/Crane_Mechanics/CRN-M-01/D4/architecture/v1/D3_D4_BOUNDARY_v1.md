# CRN-M-01
# D3 → D4 Boundary v1

| Область | D3 | D4 |
|---|---|---|
| Причинный анализ | строит конкурирующие модели | выбирает и критикует методы моделей |
| D/d | интерпретирует геометрию | review design/check method и чувствительность |
| Контакт | качественная/упрощённая модель | иерархия контактных моделей, limitations |
| Усталость | механизмы и history | критика S–N / Miner / spectrum methods |
| Remaining life | запрещено считать | только source-bound review / method critique |
| Кручение | модели torque/rotation | интерпретация испытаний и boundary conditions |
| Барабан | causal map | method selection / sensitivity / specialist escalation |
| Цепь | износ/шаг/колесо | advanced compatibility / contact model critique |
| НК | понимает ограничения визуального контроля | интерпретирует метод и границы; не заменяет специалиста |
| Источники | выбирает применимый документ | разрешает конфликт и hierarchy |
| Числа | корректно применяет | sensitivity / uncertainty / source-bound calculation |
| Итог | ограниченный технический вывод | экспертное review с audit trail |
| Полномочия | не притворяется экспертом | явно определяет handoff / authority boundary |

## Ключ

D4 не измеряется количеством формул.

D4 измеряется способностью ответить:

> **Почему именно этот метод допустим здесь — и почему другой метод здесь будет вводить в заблуждение?**
