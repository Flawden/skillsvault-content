# Source Notes v1

## ISO 16625:2025
Тип: INTERNATIONAL STANDARD  
Статус: Published, Edition 2, 2025-02.

Публично подтверждено:
- критерии выбора стальных канатов для кранов;
- proof of competence;
- влияние геометрии канатного привода;
- влияние геометрии барабана;
- влияние геометрии блока;
- не относится к волоконным канатам.

Использовано для:
- system selection model;
- запрета выбора только по канату.

Не использовано:
- закрытые формулы;
- таблицы;
- коэффициенты.

---

## ГОСТ 33710-2015
Тип: NATIONAL / INTERSTATE STANDARD  
Статус: Действует.

Публично подтверждено Росстандартом:
- критерии выбора канатов;
- минимальные коэффициенты запаса прочности Zp;
- зависимость от назначения, режима работы, типа каната, типа барабана;
- связь с минимальным разрывным усилием.

Использовано:
- российская design-check рамка;
- подтверждение многопараметричности выбора.

Не воспроизводились:
- таблицы;
- точные коэффициенты;
- расчётные процедуры.

---

## ISO 2408:2017
Тип: INTERNATIONAL PRODUCT STANDARD  
Статус: Published / Confirmed.

Публично подтверждено:
- изготовление;
- испытания;
- приёмка;
- упаковка;
- маркировка;
- сертификат;
- определённая область круглопрядных и уплотнённых канатов.

Использовано:
- граница «канат как изделие» против «канат как выбранный элемент крана».

## verope Technical Brochure, April 2026
Тип: MANUFACTURER TECHNICAL SOURCE.

Использовано только как OEM-пример того, что:
- радиальная устойчивость construction-dependent;
- изменение диаметра под нагрузкой важно для multi-layer;
- crane geometry / drum system влияют на выбор;
- swivel suitability construction-specific.

Все product-specific указания остаются product-specific.

Не универсализированы:
- проценты;
- углы;
- lay recommendations;
- swivel rules.
