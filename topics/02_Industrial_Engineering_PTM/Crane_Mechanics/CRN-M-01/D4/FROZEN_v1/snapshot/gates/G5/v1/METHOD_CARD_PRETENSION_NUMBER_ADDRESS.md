# D4 Method Card
# Процент предварительного натяжения: полный адрес числа

## Число №1

Пример производителя:

```text
~10%
OF NOMINAL ROPE LOAD
```

## Число №2

Учебный материал производителя со ссылкой на ISO 4309:

```text
2.5–5%
OF MINIMUM BREAKING LOAD
```

---

# Почему нельзя сравнить 10 > 5

Потому что:

```text
nominal rope load
≠
minimum breaking load
```

---

# Обязательные поля

Перед использованием процента:

- процент;
- знаменатель;
- источник;
- редакция / дата;
- объект;
- цель;
- mandatory / recommendation / practical experience;
- applicability.
