## ISO 4301-1:2016
Статус:
- Published;
- Edition 3;
- confirmed in 2021;
- current.

Публичная область:
- общая классификация кранов и механизмов;
- total number of working cycles;
- load spectrum factor;
- average displacements.

Использовано:

- закрытые таблицы классов;
- коэффициенты.

https://www.iso.org/standard/63070.html

# Главный source guard

```text
КЛАСС КРАНА
→
РЕСУРС КАНАТА
```

Он создаёт правильный мост:

```text
КЛАССИФИКАЦИЯ
→
ФАКТИЧЕСКАЯ СЛУЖБА
→
ЛОКАЛЬНАЯ ИСТОРИЯ
→
ИНСПЕКЦИОННОЕ EVIDENCE
→
SOURCE-BOUND РЕШЕНИЕ
```
