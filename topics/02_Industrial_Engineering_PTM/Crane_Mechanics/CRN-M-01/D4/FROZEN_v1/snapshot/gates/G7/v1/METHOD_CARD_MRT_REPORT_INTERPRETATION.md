# D4 Method Card
# Как читать отчёт магнитного контроля каната

## 1. Идентификация

- канат;
- конструкция;
- диаметр;
- прибор / тестовая голова;
- дата;
- координатная база;
- процедура;
- оператор / организация.

## 2. Что зарегистрировано

- LF?
- LMA?
- оба?
- иной параметр?

## 3. Есть ли baseline

Если да:
- сравнима ли конфигурация?
- совпадает ли координатная база?
- одинаков ли способ измерения?

## 4. Условия

- скорость;
- зазор;
- направление;
- состояние поверхности;
- доступ;
- повторяемость.

## 5. Корреляция

Сопоставить:
- visual;
- diameter;
- drum/sheave coordinate;
- historical damage;
- previous MRT.

## 6. Критерий

Отдельно найти:
- применимый стандарт / ФНП / OEM;
- редакцию;
- параметр;
- область.

## 7. Выход

- SIGNAL CONFIRMED
- DETERIORATION SUPPORTED
- INTERNAL-DAMAGE MODEL SUPPORTED
- CRITERION REACHED
- DATA INSUFFICIENT
- REPEAT / SPECIALIST REVIEW REQUIRED

Нельзя перескакивать через уровни.
