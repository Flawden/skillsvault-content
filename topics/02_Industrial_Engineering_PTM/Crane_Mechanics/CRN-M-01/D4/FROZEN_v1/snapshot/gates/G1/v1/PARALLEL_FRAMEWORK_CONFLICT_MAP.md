# CRN-M-01 — D4-G1
# Карта параллельных редакций и потенциальных конфликтов

| Область | Российская действующая ветка | Международная текущая ветка | Экспертный guard |
|---|---|---|---|
| Общая терминология кранов | ГОСТ 33709.1-2015 | ISO 4306-1:2026 | Не считать определения автоматически идентичными |
| Выбор канат / барабан / блок | ГОСТ 33710-2015 | ISO 16625:2025 | ГОСТ основан на более старой ISO 16625:2013; не смешивать таблицы/формулы |
| Уход / осмотр / браковка каната | ГОСТ 33718-2015 | ISO 4309:2017 | ГОСТ основан на ISO 4309:2010; критерии сравнивать только source-local |
| Терминология канатов | ГОСТ EN 12385-2-2015 | ISO 17893:2004 + Amd1:2010 | Сохранять систему обозначений источника |
| Продуктовые требования каната | ГОСТ EN 12385-1/-4 и др. | ISO 2408:2017 | Проверять область типа каната и утверждения |
| Вращательные свойства | — / OEM / другие применимые документы | ISO 21669:2005 | Это испытательный метод, не универсальный закон |
| Эксплуатационная допустимость ПС | ФНП №461 + эксплуатационная документация | ISO не заменяет российскую регуляторную рамку | Сначала определить юридическую/эксплуатационную применимость |
