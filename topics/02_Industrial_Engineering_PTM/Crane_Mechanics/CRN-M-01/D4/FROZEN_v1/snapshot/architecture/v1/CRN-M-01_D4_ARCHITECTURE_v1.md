# 1. Главная идея D4

D4 нельзя определять как:

> «ещё больше терминов, формул и страниц после D3».

D3 уже учит:
- строить конкурирующие модели;
- выбирать различающие измерения;
- работать с неполными данными;
- ограничивать технический вывод.

D4 должен добавить **новый класс способности**:

```text
D3
→ КАКАЯ МОДЕЛЬ ЛУЧШЕ ОБЪЯСНЯЕТ СЛУЧАЙ?

D4
→ КАКУЮ МОДЕЛЬ / МЕТОД ВООБЩЕ ДОПУСТИМО ПРИМЕНЯТЬ,
   НА КАКИХ ДОПУЩЕНИЯХ,
   НАСКОЛЬКО РЕЗУЛЬТАТ ЧУВСТВИТЕЛЕН,
   ЧТО ДЕЛАТЬ ПРИ КОНФЛИКТЕ ИСТОЧНИКОВ,
   И ГДЕ НУЖНО ПЕРЕДАТЬ РАБОТУ
   ПРОЕКТИРОВЩИКУ / ЭКСПЕРТУ / НК-СПЕЦИАЛИСТУ.
```

# 2. D4 Competency Contract

После D4 учащийся должен уметь в сложном, высокорисковом или методически неоднозначном случае:

1. определить, какой класс инженерной задачи перед ним;
2. выбрать применимый метод анализа из нескольких возможных;
3. объяснить допущения и ограничения выбранного метода;
4. проверить область действия стандарта, OEM-методики, статьи или расчётной модели;
5. сравнить конфликтующие источники по их приоритету и применимости;
6. выполнить допустимый проверочный расчёт или анализ чувствительности, если метод источникно определён;
7. не восстанавливать закрытые нормативные таблицы и коэффициенты по памяти;
8. оценить, какие входные данные доминируют в неопределённости результата;
9. интерпретировать специализированные результаты контроля только в пределах компетенции метода;
10. различить:
   - диагностический анализ;
   - проверочный расчёт;
   - проектный расчёт;
   - экспертное заключение;
   - формальную сертификацию;
11. сформулировать техническое review с явными допущениями, рисками и границами;
12. определить точку обязательного привлечения изготовителя, проектировщика, НК-специалиста или экспертной организации.

# 3. Что D4 НЕ даёт автоматически

Даже после D4 человек не получает автоматически:

- право проектировать грузоподъёмный механизм;
- право официально продлевать ресурс;
- право выполнять НК без квалификации;
- право сертифицировать канат или цепь;
- право изменять конструкцию ПС;
- право заменять расчёт изготовителя собственным учебным расчётом.

D4 = экспертная грамотность и глубокий инженерный анализ.

D4 ≠ юридическая / профессиональная аттестация.

# ЧАСТЬ I — Экспертная архитектура источников и методов
## Блоки 1–5

### Блок 1 — Тип инженерного утверждения

Разделить:

```text
Нормативное требование
OEM-рекомендация
испытательный метод
расчётная модель
эмпирическая корреляция
научное исследование
экспертная гипотеза
```

### Блок 2 — Иерархия применимости

Не просто:
> какой источник «авторитетнее».

А:
> какой источник действительно относится к этому объекту, состоянию и вопросу.

### Блок 3 — Конфликт источников

Что делать, если:
- стандарт говорит одно;
- OEM — другое;
- старая инструкция — третье;
- новая статья показывает четвёртое.

### Блок 4 — Метод и область валидности

Любая модель получает:

```text
входы
допущения
диапазон применимости
выход
ограничения
```

### Блок 5 — Экспертный audit trail

Как сохранить:
- источник;
- редакцию;
- входы;
- расчёт;
- допущения;
- неопределённость;
- решение.

# 6. Внешние опоры, которые НЕ нужно превращать в ядро CRN-M-01

Есть знания, важные для эксперта, но принадлежащие более широкому графу.

## 6.1. Классификация режима работы крана

ISO 4301-1 и ISO 4301-5:
- циклы;
- спектр нагрузки;
- перемещения.

Нужны как внешний контекст для fatigue/duty.

Но полная классификация крана — отдельная компетенция.

## 6.2. Мониторинг расчётного периода

ISO 12482:
- фактический duty;
- сравнение с исходным design duty;
- фокус специальных инспекций.

Для `CRN-M-01` — внешний reference dependency.

Не ядро темы канатов и цепей.

## 6.3. Инспекции мостовых и козловых кранов

ISO 9927-1 / ISO 9927-5:
важны для общей инспекционной архитектуры.

Но не должны раздувать Topic до «экспертизы всего крана».

# 7. Формат D4: не всё должно быть Lesson

В D4 вводится три типа материала.

## TYPE A — CORE LESSON

То, что эксперт обязан понимать и применять самостоятельно.

## TYPE B — METHOD CARD

Карточка метода:

```text
что решает
входы
допущения
выходы
ограничения
источник
когда применять
когда не применять
```

## TYPE C — REFERENCE

Глубокая справочная зона:
- таблицы источника;
- перечень стандартов;
- OEM-методики;
- specialist methods.

REFERENCE не обязан запоминаться.

Он должен быть правильно найден и применён.

# 8. Количественная политика D4

## Q4-A — Разрешено

- проверочные расчёты по открыто подтверждённой методике;
- анализ чувствительности;
- сравнение сценариев;
- размерностная проверка;
- воспроизведение собственных вычислений из явно доступных входов.

## Q4-B — Только source-bound

- формулы стандарта;
- коэффициенты;
- таблицы;
- OEM-критерии.

Только если источник доступен и проверен.

## Q4-C — Reference only

- закрытые платные таблицы;
- proprietory OEM algorithms;
- сертификационные методы.

Не реконструировать.

## Q4-D — Запрещено выдавать как готовую компетенцию

- официальный remaining-life без полномочий и методики;
- проектирование нового канатного привода «по учебнику»;
- certification decision;
- specialised NDT execution без квалификации.
