# CRN-M-01 / D4 Practice v1 — Alignment Map

## Purpose

Practice A–H tests whether the learner can apply the D4 reasoning architecture under incomplete, conflicting and authority-bounded evidence.

It is deliberately not a recall quiz.

---

## Case alignment

| Case | Main D4 Parts | Core competence |
|---|---|---|
| A | I, IX | source applicability / authority / audit trail |
| B | II, IX | rope replacement compatibility |
| C | III, VI, IX | local mechanics / model selection / multilayer |
| D | III, IV, IX | fatigue model critique / remaining life |
| E | V, IX | rotational properties / installation / causality |
| F | VII, IX | chain–wheel compatibility / inspection vs design |
| G | VIII, IX | NDT evidence / uncertainty / safety-action boundary |
| H | I–IX | full expert synthesis / bounded technical review |

---

## D4 capabilities exercised

Across A–H the learner must demonstrate:

1. precise decision-question framing;
2. FACT / INFERENCE / ASSUMPTION / UNKNOWN separation;
3. competing-model construction;
4. source-type selection;
5. method validity boundary;
6. smallest-sufficient model selection;
7. differentiating-evidence planning;
8. sensitivity / uncertainty reasoning;
9. bounded conclusion;
10. safety and authority boundary;
11. audit trail;
12. explicit refusal to invent missing data.
