# SRC-000393 — ФНП ПС — Приказ Ростехнадзора №461, ред. 16.04.2026

## Зачем источник нужен

Актуальная российская нормативная база по ОПО с подъёмными сооружениями.

Для CRN-M-01 источник нужен как основной российский нормативный каркас по оценке работоспособности, замене и браковке стальных канатов и цепей.

## Что именно использовать для CRN-M-01

- порядок оценки работоспособности по руководству/инструкции ПС и ФНП;
- требования к замене стальных канатов;
- требования к замене стальных цепей;
- отсылку к критериям браковки цепей.
