## Freeze semantics

`CONTENT FROZEN` means:
- accepted content is immutable for the current version;
- future changes require a new version / explicit unfreeze;
- D3 may be authored against this D2 baseline;
- the frozen bundle itself is not proof of learner mastery.

Learner mastery and verification remain separate:
- D = content depth
- R = mastery
- V = verification strength
