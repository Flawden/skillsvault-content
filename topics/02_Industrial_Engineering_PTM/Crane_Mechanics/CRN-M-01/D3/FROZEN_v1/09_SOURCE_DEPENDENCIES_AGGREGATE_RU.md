# CRN-M-01 — D3
# Сводная карта источников после полной редакции

## Нормативная и стандартная основа

### Российская эксплуатационная рамка
- ФНП №461, редакция 16.04.2026.
- Пункты 190–197, 270, 272 — в пределах ранее проверенной трассировки.

### Канаты
- ISO 4309:2017 — уход, осмотр и браковка; текущая опубликованная редакция на дату проверки.
- ISO 16625:2025 — выбор канатов, барабанов и блоков.
- ISO 21669:2005 — определение вращательных свойств канатов.
- ISO 2408:2017 — требования к стальным канатам.
- ISO 17893:2004 + Amd1:2010 — терминология / классификация.
- ГОСТ 33718-2015 — российская действующая рамка по стальным канатам в своей области.

### Цепи
- ISO 7592:1983 — калиброванные круглозвенные цепи, работающие по цепным колёсам.
- ISO 3077:2001 — цепи высокой точности T / DAT / DT.
- ISO 3076:2012 — цепи средней точности для стропов.
- ISO 16872:2015 — VH для ручных талей.
- ISO 1834:1999 — общие условия приёмки.
- ГОСТ 30188-97 — калиброванные высокопрочные цепи для работы на звёздочках; не для стропов.
- ГОСТ EN 818-7-2010 — T / DAT / DT; действует в РФ с 2025-01-01.

## Научная поддержка

Использовалась только как механическая поддержка и не как источник универсальных нормативных чисел:
- bending-over-sheave fatigue;
- rope–sheave tribology;
- internal wire fretting;
- first-wire-break redistribution;
- bending–tension fatigue;
- axial–torsional coupling;
- fatigue / stress state of hoist chains.

## Критические ограничения источников

1. Платные таблицы ISO не реконструируются по памяти.
2. Численные требования manufacturer guidance не становятся универсальным нормативом.
3. Значения из разных определений D не смешиваются.
4. Проценты с разными знаменателями не сравниваются напрямую.
5. OEM-пределы цепей не переносятся между талями.
6. Экспериментальные S–N / ресурсные зависимости не универсализируются.
7. Draft-редакции стандартов не заменяют текущие опубликованные версии.
