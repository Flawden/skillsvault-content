# Зачем эта практика

D3 нельзя подтвердить вопросом:

> «Что такое отношение D/d?»

или:

> «Где измерять износ цепи?»

Человек должен показать, что умеет работать с незнакомым техническим случаем.

Поэтому практика построена как восемь кейсов:

```text
A — путь нагрузки
B — изгиб и D/d
C — блок / ручей / контакт
D — циклы и усталость
E — кручение и вращение
F — многослойный барабан
G — цепь и цепное колесо
H — интегрированный незнакомый случай
```

Во всех кейсах оценивается не угадывание «правильной причины», а качество инженерного рассуждения.

Разрешён и иногда является лучшим ответом:

> **«Имеющихся данных недостаточно для окончательного вывода».**

Но только если человек объяснил:
- какие именно данные отсутствуют;
- какие модели из-за этого нельзя различить;
- что нужно проверить следующим шагом.

---

# Универсальный формат ответа

Для каждого кейса учащийся должен выдать:

## 1. Идентификация объекта
Что именно анализируется и какие характеристики объекта принципиальны.

## 2. Факты
Отдельно:
- наблюдения;
- измерения;
- документальные факты.

Без смешения с причинами.

## 3. Путь нагрузки / контактная система
Как проходит нагрузка и какие сопряжённые элементы участвуют.

## 4. Конкурирующие модели
Не менее двух для нетривиального случая.

Для каждой:
- физический механизм;
- почему она правдоподобна;
- что она предсказывает.

## 5. Различающие данные
Что сильнее всего разделит модели.

## 6. Ограниченный технический вывод
Что:
- поддерживается;
- остаётся альтернативой;
- пока неизвестно.

## 7. Документальный следующий шаг
Какой документ / характеристику / методику нужно открыть или подтвердить.

# ПРАКТИКА A
# Путь нагрузки: «одинаковый груз» не означает одинаковую работу ветвей

## Исходная ситуация

Мостовой кран использует канатную систему с несколькими ветвями и блоками.

После ремонта механизма подъёма оператор сообщает:

> «Груз тот же самый, но канат возле одного блока стал заметно сильнее изнашиваться».

Известно:

- масса типичного груза не менялась;
- канат заменён не был;
- один из блоков после ремонта снимался и устанавливался обратно;
- схема запасовки визуально кажется прежней;
- точное положение осей блоков после ремонта не измерялось;
- натяжение отдельных ветвей не измерялось;
- один участок каната показывает более выраженный наружный износ;
- аварийной перегрузки по журналу не зарегистрировано.

## Задача

Построй причинный анализ, начиная не с дефекта, а с пути нагрузки.

Нужно:

1. нарисовать словами или схемой возможный путь нагрузки;
2. назвать минимум три причины, почему одинаковая масса груза не гарантирует одинаковую механическую историю всех ветвей;
3. отделить:
   - изменение общей нагрузки;
   - изменение распределения нагрузки;
   - изменение контакта;
4. построить минимум три конкурирующие модели;
5. для каждой записать предсказания;
6. выбрать три наиболее различающих измерения;
7. написать промежуточный технический вывод.

## Ограничения

Нельзя:
- считать натяжение всех ветвей одинаковым только по симметричной схеме;
- объявлять блок виновным только потому, что дефект рядом;
- вычислять точные силы без достаточной геометрии и граничных условий.

## Что должно проявиться в хорошем ответе

- путь нагрузки как система;
- роль геометрии и сопряжённых деталей;
- различие нагрузки и контакта;
- честное указание неизвестного.

# ПРАКТИКА B
# Изгиб и D/d: одинаковое число не гарантирует одинаковую историю

## Исходные данные

Один и тот же канат проходит последовательно через два блока.

Номинальный диаметр каната:

```text
d_n = 20 мм
```

Измеренный фактический диаметр в рабочем состоянии без нагрузки:

```text
d_ф = 19,4 мм
```

Для блока A:

```text
D_c = 400 мм
```

Для блока B:

```text
D_c = 500 мм
```

После блока B направление изгиба меняется на противоположное относительно предыдущего изгиба.

На участке после блока B наблюдается большее число наружных обрывов проволок.

## Задача

1. Рассчитать описательные отношения `D_c/d_n` для обоих блоков.
2. Рассчитать безразмерную кривизну `κd_n = 2/(D_c/d_n)`.
3. Объяснить, что эти числа реально говорят о геометрии.
4. Объяснить, чего они **не** говорят.
5. Сравнить механическую историю участка около A и B.
6. Построить минимум три модели, объясняющие большее повреждение после B.
7. Указать, какие данные нужны для различения:
   - геометрии блока;
   - обратного изгиба;
   - контактной проблемы;
   - различий цикличности.
8. Сформулировать вывод без расчёта остаточного ресурса.

## Ловушка

Ответ:

> «У B больше D/d, значит B точно безопаснее»

не принимается.

Нужно учитывать всю историю:

```text
геометрия изгиба
+
направление изгиба
+
контакт
+
циклы
```

## Ограничения

Нельзя:
- превращать D/d в универсальный калькулятор ресурса;
- делать точный вывод о напряжениях отдельных проволок по диаметру каната и блока;
- подменять `D_c` другим определением D без явного указания.

# ПРАКТИКА C
# Блок и ручей: контактная гипотеза должна выдержать измерения

## Исходные данные

На одном канате два рабочих блока.

Измеренный фактический диаметр каната:

```text
19,2 мм
```

Ручей блока S1 по фактическому измерению имеет условный эффективный поперечный размер:

```text
19,8 мм
```

Ручей блока S2:

```text
21,0 мм
```

На S1:
- наружный износ выраженный;
- след контакта широкий;
- боковой асимметрии почти нет.

На S2:
- износ меньше;
- но на одной стороне каната имеются продольные следы;
- на щеке блока видны следы бокового контакта.

Угол подхода каната к блокам не измерялся.

Применимый OEM-предел по ручью в условии не дан.

## Задача

1. Не используя универсальный «правильный процент», сравнить две контактные системы.
2. Построить минимум четыре модели:
   - тесная посадка;
   - чрезмерно свободная посадка;
   - боковой контакт / перекос;
   - загрязнение / абразивный вклад.
3. Для каждой модели записать ожидаемые следы.
4. Выбрать измерения, которые сильнее всего разделят S1 и S2.
5. Объяснить, почему визуальное «ручей широкий» или «ручей тесный» недостаточно.
6. Назвать документ, без которого нельзя превратить геометрическое сравнение в окончательный критерий допустимости.
7. Дать ограниченный технический вывод по каждому блоку отдельно.

## Ловушка

Число отношения размера ручья к диаметру каната можно использовать как **описательную характеристику**.

Но нельзя объявлять:
- S1 непригодным;
- S2 правильным

только по одному универсальному проценту, которого в условии нет.

# ПРАКТИКА D
# Усталость: одинаковая максимальная нагрузка, разная история

## Исходные данные

Есть три одинаковых каната одной конструкции.

У всех:

```text
F_max = 100 кН
F_min = 20 кН
```

### Канат A
Работает почти прямо:
- изменение натяжения 20 → 100 → 20 кН;
- существенного изгиба на рабочем участке нет.

### Канат B
Имеет ту же историю натяжения,
но каждый цикл проходит через блок.

### Канат C
Имеет ту же историю натяжения,
проходит два блока,
а второй создаёт изгиб противоположного направления относительно первого.

Известно только:
- одинаковые `F_max` и `F_min`;
- одинаковое число подъёмов.

Диаметры блоков, конструкция контакта и состояние смазки не даны.

## Задача

1. Рассчитать:
   - среднюю силу;
   - диапазон силы;
   - амплитуду изменения силы.
2. Объяснить, почему эти одинаковые значения не делают три истории одинаковыми.
3. Описать:
   - циклическое растяжение;
   - повторный изгиб под натяжением;
   - обратный изгиб.
4. Попытаться ранжировать канаты по вероятной усталостной тяжести.
5. Если точное ранжирование невозможно — указать, **почему именно**.
6. Назвать недостающие данные, которые сильнее всего изменят вывод.
7. Объяснить, почему первое обнаруженное разрушение проволоки меняет последующую историю.
8. Запретить себе расчёт точного оставшегося числа циклов.

## Главная проверка

Хороший ответ может сказать:

> «B и C имеют дополнительные изгибные циклы по сравнению с A, но без геометрии блоков и контактных условий невозможно честно количественно ранжировать B против C».

Это сильнее, чем придуманная точность.

# ПРАКТИКА E
# Кручение: крюковая подвеска начала вращаться после замены каната

## Исходная ситуация

После замены грузового каната оператор сообщает:

> «Раньше крюк почти не крутился, теперь под грузом разворачивается».

Факты:

- новый канат имеет тот же номинальный диаметр;
- точная конструкция старого и нового канатов пока не сопоставлена;
- запасовка по схеме не менялась;
- монтаж выполнялся с новой бухты;
- данных о числе случайно внесённых оборотов при монтаже нет;
- вертлюг в системе есть;
- его допустимость для конкретной конструкции нового каната по документации ещё не проверена;
- вращение увеличивается с нагрузкой;
- без нагрузки почти отсутствует;
- на одной ветви заметно изменение характера свивки;
- угол подхода каната к барабану не измерен.

## Задача

Построить минимум пять моделей:

1. собственный крутящий отклик конструкции каната;
2. монтажно внесённое закручивание;
3. геометрия запасовки / неодинаковые ветви;
4. влияние барабана и угла подхода;
5. несовместимость режима работы с вертлюгом.

Для каждой:
- объяснить механизм;
- указать предсказание;
- назвать различающий признак.

Далее:

6. объяснить, почему вращение крюка не является прямым измерением крутящего момента каната;
7. объяснить, почему «малокрутящийся» не означает «нулевой крутящий момент»;
8. указать, какой документ обязателен перед рекомендацией по вертлюгу;
9. сформулировать промежуточный вывод без универсальной рекомендации «убрать/поставить вертлюг».

## Красная линия

Запрещены ответы:

> «Крутит — поставьте вертлюг».

и

> «Вертлюг всегда вреден».

# ПРАКТИКА F
# Многослойный барабан: дефект повторяется в одной функциональной зоне

## Исходные данные

Новый канат установлен на многослойный барабан.

Через несколько месяцев обнаружено:

- локальное сплющивание;
- наружный износ;
- группа обрывов наружных проволок;
- дефектная зона находится примерно в 31 м от принятой базы;
- по рабочей карте эта координата при типичном положении крюка попадает в переходную зону второго слоя;
- в нижнем слое заметны небольшие зазоры;
- точное предварительное натяжение при установке не записано;
- фактическое уменьшение диаметра каната под рабочей нагрузкой не измерено;
- угол подхода каната к барабану не измерен;
- предыдущий канат тоже повреждался «в этом районе», но точной координаты не сохранили.

## Задача

Построить минимум четыре модели:

1. повышенная тяжесть переходной зоны;
2. врезание верхнего витка в нестабильный нижний пакет;
3. недостаточная радиальная устойчивость конкретной конструкции каната;
4. неблагоприятная геометрия подхода / укладки.

Нужно:

5. построить карту:
   `координата каната ↔ слой ↔ виток ↔ переходная зона ↔ положение крюка`;
6. объяснить, что именно делает повтор в одной функциональной зоне сильным доказательством;
7. отделить отсутствие записи о предварительном натяжении от доказательства плохого натяжения;
8. перечислить пять наиболее различающих измерений;
9. объяснить, почему нельзя назначить универсальный процент предварительного натяжения;
10. написать технический вывод с ранжированием моделей.

## Ловушка

Фраза:

> «На предыдущем канате было там же»

не равна подтверждённому повтору, пока нет воспроизводимых координат.

# ПРАКТИКА G
# Цепь и цепное колесо: «цепь вытянулась»

## Исходная ситуация

Электрическая цепная таль работает в основном между двумя постоянными высотами.

Через несколько месяцев после замены цепи обнаружено:

- на одной группе из пяти последовательных звеньев сумма шагов выросла заметнее, чем в соседних группах;
- внутренние контактные поверхности этой группы изношены;
- одно из пяти звеньев имеет небольшую асимметрию формы;
- остальная цепь выглядит лучше;
- грузовое цепное колесо после прошлой замены цепи не меняли;
- документация подтверждает номинальный диаметр новой цепи;
- точный тип / шаг / класс новой цепи по сертификату ещё не сопоставлен с OEM-требованием;
- цепь иногда идёт рывком около одной и той же рабочей высоты;
- смазка наносилась снаружи, попадание в контактные зоны не проверялось.

## Задача

1. Разделить три модели:
   - контактный износ;
   - остаточная деформация;
   - их комбинация.
2. Объяснить, почему увеличение суммы шагов не доказывает пластическое растяжение материала.
3. Построить модель `цепь ↔ цепное колесо ↔ направляющая`.
4. Объяснить роль постоянной рабочей высоты.
5. Назвать минимум четыре причины рывкового движения.
6. Перечислить, что нужно проверить до установки ещё одной новой цепи.
7. Объяснить, почему правильный номинальный диаметр не доказывает совместимость.
8. Отдельно сформулировать:
   - причинный вывод;
   - эксплуатационный / документальный следующий шаг.
9. Не переносить OEM-пределы другой тали.

# ПРАКТИКА H
# Интегрированный незнакомый случай: два досье, один метод мышления

## Замысел

Учащийся получает два независимых технических досье.

Нужно решить оба и показать:

> один и тот же инженерный метод переносится между канатом и цепью.

---

## ДОСЬЕ H1 — канат

На грузовом канате:

- наружный износ;
- отдельные обрывы;
- дефектная зона повторяется около одной высоты крюка;
- эта координата проходит сначала через блок S4, затем через многослойный барабан;
- ручей S4 ещё не измерен;
- на барабане есть следы нарушения укладки около переходной зоны;
- после последней замены каната вращение подвески под нагрузкой увеличилось;
- точная конструкция старого каната неизвестна;
- новый канат идентифицирован по паспорту;
- остаточный ресурс никто не рассчитывал.

### Требование

Построить:
- минимум четыре конкурирующие модели;
- их предсказания;
- различающие измерения;
- карту координаты;
- документальный следующий шаг;
- ограниченный вывод.

---

## ДОСЬЕ H2 — цепь

На другой единице оборудования:

- цепь идёт рывками;
- локально выросла сумма шагов нескольких звеньев;
- износ находится на внутренних контактных поверхностях;
- рабочая высота почти постоянна;
- колесо старое;
- цепь заменена недавно;
- по документам пока подтверждён только диаметр;
- на одном звене есть изменение формы;
- история перегрузок неполная.

### Требование

Построить:
- минимум три конкурирующие модели;
- различающие измерения;
- карту группы звеньев;
- разделение износа и остаточной деформации;
- проверку совместимости;
- ограниченный вывод.

---

## Финальная часть H

После двух досье учащийся должен ответить:

1. Какие элементы метода анализа были одинаковыми в H1 и H2?
2. Что было специфично только для каната?
3. Что было специфично только для цепи?
4. Где в обоих случаях возникает риск перепутать критерий состояния с причиной?
5. Какое утверждение в каждом досье было бы самым опасным, если сказать его слишком уверенно?
6. Какие данные нужно начать сохранять в эксплуатации, чтобы следующий случай расследовался сильнее?

# Условия прохождения всей практики D3

Практика считается выполненной содержательно только если учащийся:

- не угадывает одну причину по первому симптому;
- строит конкурирующие модели;
- связывает каждую модель с проверяемыми предсказаниями;
- выбирает различающие данные;
- использует пространственную / циклическую историю;
- проверяет сопряжённые детали;
- не смешивает нормативный критерий и причинный вывод;
- не переносит числа между областями применения;
- умеет сказать «данных недостаточно»;
- не считает остаточный ресурс без валидированной модели;
- формулирует ограниченный технический вывод.

---

# Что практика специально НЕ проверяет

Эта практика не требует:

- проектирования каната;
- проектирования цепи;
- проектирования блока / барабана / цепного колеса;
- точного расчёта контактных напряжений;
- КЭ-моделирования;
- определения остаточного ресурса;
- экспертного анализа разрушения;
- выполнения НК вместо квалифицированного специалиста;
- юридического разрешения на эксплуатацию.

Это граница D3.
