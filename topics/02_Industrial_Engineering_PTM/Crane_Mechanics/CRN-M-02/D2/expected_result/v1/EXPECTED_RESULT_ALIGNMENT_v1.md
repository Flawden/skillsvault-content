## Minimum evidence outputs

1. `SYSTEM / MODE`;
2. `ROPE PATH`;
3. `CONTACT-NODE MAP`;
4. `LOCAL-TENSION MAP`;
5. `FREE BODY + FORCE OWNERSHIP`;
6. `GEOMETRY / SPOOLING STATE`;
7. `KINEMATIC CARD` or `MOMENT CARD` when relevant;
8. `MODEL STATUS`;
9. `SOURCE / REFERENCE-GEOMETRY CHECK` when a numeric/equipment claim is attempted;
10. `BOUNDED CONCLUSION / FIELD AUTHORITY BOUNDARY`.

## Coverage rationale

- Practice A–K already spans the complete D2 applied-mechanics spine without introducing a separate answer key.
- Practice Reasoning demonstrates acceptable bounded paths, including legitimate `SIMPLE`, `QUALITATIVE APPLIED`, `SOURCE / OEM REQUIRED` and `NOT YET DEMONSTRATED` outcomes.
- ER-D2-01…11 are directly traceable to known Practice cases and Lesson guards.
- ER-D2-12 intentionally cannot be closed by A–K alone because genuine transfer requires an unseen layout/context.
- A correct stop/escalation is success when the requested model or authority is not demonstrated.

## Transfer requirement

Known-case performance alone is insufficient.

Verification must include at least one unseen applied case that requires an integrated chain:

```text
system/mode
→ rope path
→ contact nodes
→ local Ti
→ named FBD
→ geometry/spooling
→ model status
→ bounded conclusion
```

The unseen case must not be a trivial renaming or renumbering of A–K.

## Challenge / delta requirement

Verification should mutate one meaningful input after the first answer. Accepted mutation families:

- selected free body;
- rope direction / reference geometry;
- block route/location;
- winding/spooling state;
- acceleration/transient condition;
- source definition/reference geometry.

The learner must identify which parts of the prior model become stale and rebuild them.

## Candidate blocking failures

The next stage must define severity/non-compensability for at least:

1. one-rope-equal-`T` shortcut;
2. FBD ownership collapse;
3. universal `ωr` overreach;
4. layer radius substituted for moment arm;
5. observation-to-verdict leap;
6. terminology-only numeric authority;
7. quasi-static-as-dynamic authority;
8. classification-factor invention;
9. comprehension-to-field-authority leap.

## Claim/source boundary

Expected Result introduces no new normative threshold.

Exact D/d, groove geometry, angle limits, real efficiency factors, allowable stresses/contact pressures, discard/repair criteria, classification assignments and equipment-specific interventions remain locked to the exact applicable source/OEM/passport/procedure and required authority.
