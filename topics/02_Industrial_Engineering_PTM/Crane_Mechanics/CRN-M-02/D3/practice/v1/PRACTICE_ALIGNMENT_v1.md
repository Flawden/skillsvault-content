# CRN-M-02 / D3 Practice Alignment v1

## Назначение

Practice A–L проверяет только уже введённые D3 causal-analysis models и guards. Новый нормативный, proof/design или remaining-life слой не вводится.

| Case | Primary D3 skill | Lesson anchors | Guard / stop condition |
|---|---|---|---|
| A | competing causal models from one signature | §1–7, §12–13 | plausible/support/root-cause boundary |
| B | same signature vs different history/path | §8, §11, §27 | correlation / history guard |
| C | observability before negative evidence | §17–18, §29 | RT-D3 non-detection guard |
| D | falsifiable `H_data` | §4, §29, §32 | `H_data` is not a trash bin |
| E | present snapshot vs accumulated history | §11–12 | snapshot ≠ history |
| F | dynamic-state rebuild / unknown acceleration | §9–10, §32 | Newton–Euler scope; not measured ≠ zero |
| G | before/after change bundle / confounders | §19–20 | before/after ≠ one cause proven |
| H | directional sensitivity without causal identification | §14, §19 | sensitivity ≠ causal effect |
| I | question-specific evidence roles | §16, §28–29 | evidence hierarchy is not universal ranking |
| J | source existence vs formal-method authority | §16, §23–24, authority gate | source exists ≠ method/authority unlocked |
| K | natural-experiment-like historical comparison | §20 | comparison ≠ controlled experiment |
| L | integrated causal case file / evidence plan / bounded conclusion | §22–24, §31 | D3 bounded support, not formal root cause |

## Coverage invariants

Practice must make the learner demonstrate all of the following at least once:

- neutral separation of observed signature from explanation;
- at least two competing hypotheses before causal closure;
- prediction and `WOULD BE UNEXPECTED` for candidate mechanisms;
- evidence matrix usage;
- distinguishing-data selection;
- observability/detectability check before negative evidence;
- falsifiable `H_data` when data quality can explain the signature;
- present-state versus accumulated-history separation;
- dynamic-state model rebuild without invented coefficients;
- confounder/change-bundle reasoning;
- qualitative sensitivity without causal-identification overclaim;
- question-specific evidence roles;
- source/method/data/authority separation;
- unknown register;
- explicit D3 model status;
- bounded technical conclusion;
- integrated transfer across several mechanism families.

## Claim locks

The following remain intentionally absent:

- formal root-cause certification;
- ISO paid dynamic factors or load combinations;
- fatigue-life / remaining-life numbers;
- proof-of-competence calculations;
- equipment-specific acceptance/discard limits;
- specialist NDT interpretation;
- design verification;
- field modification / rerouting / repair authority.

## Separation from Practice Reasoning

`CRN-M-02_D3_PRACTICE_v1.md` contains prompts, evidence fragments and adversarial traps only. Worked reasoning, acceptable alternate model paths, evidence-matrix updates and explicit failure analysis belong to the next stage.
