# CRN-M-02 / D1 Expected Result v1 — Alignment

## Expected Result dimensions

| ID | Observable competence | Main Practice evidence |
|---|---|---|
| ER-01 | Выбор движущейся системы | A–H |
| ER-02 | Концы каната и статус закреплений | A, C, E, F, H |
| ER-03 | Rope-path tracing | A–C, E, F, H |
| ER-04 | Force-transfer map, включая moving dead end | B, C, E, F, H |
| ER-05 | Simple-model decision / stop / escalation | A, C, E, F, H |

## Evidence outputs

Минимальный D1 evidence package:

1. `MOVING ASSEMBLY`;
2. `ENDPOINT / ATTACHMENT MAP`;
3. `ROPE PATH`;
4. `FORCE-TRANSFER MAP`;
5. `MODEL STATUS`;
6. `IDEAL MECHANICS CARD` — только если simple model доказана;
7. `BOUNDED CONCLUSION / FIELD BOUNDARY`.

## Coverage rationale

- Practice A–H проверяет последовательность чтения запасовки, а не память формулы.
- Practice Reasoning закрепляет multiple-valid-path handling, moving dead end и `ESCALATE BEYOND D1`.
- ER-08 частично опирается на Lesson, потому что Practice намеренно сосредоточена на чтении запасовки и не пытается превратить каждый компонентный термин в отдельный кейс.
- ER-10 намеренно не может быть закрыт известными кейсами: transfer требует нового рисунка/описания.

## Transfer requirement

Known-case performance alone is insufficient.

Verification должен включить минимум один unseen case, где обучающийся обязан самостоятельно пройти:

```text
moving assembly
→ endpoints
→ rope path
→ force map
→ model status
→ ideal mechanics OR stop/escalation
→ field boundary
```

Незнакомый кейс может корректно завершиться без числа.

## Candidate blocking failures

Следующий stage должен определить тяжесть минимум для:

- block-count shortcut;
- dead-end deletion;
- formula-first;
- scalar-model overreach;
- invented numeric authority;
- comprehension-to-authority leap.

## Claim/source boundary

Expected Result не открывает новые нормативные числа.

Любые equipment-specific dimensions, actual reeving approval, D/d, groove geometry, fleet-angle limits, real efficiency or acceptance criteria остаются за пределами D1 без применимого документа/OEM/passport evidence.
