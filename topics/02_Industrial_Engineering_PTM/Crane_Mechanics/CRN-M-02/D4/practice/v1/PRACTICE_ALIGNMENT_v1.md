# CRN-M-02 / D4 Practice v1 — Alignment Map

## Назначение

Practice A–J проверяет применение D4 method-governance architecture под неполными, конфликтующими и authority-bounded данными. Новый normative/proof/remaining-life слой не вводится.

| Case | Main D4 Parts | Core competence | Primary guard |
|---|---|---|---|
| A | I, IX | question/claim decomposition; source/method/authority map | one object ≠ one method |
| B | II, V | configuration provenance; boundary-value problem | same ratio ≠ same load path |
| C | III, VI | model fidelity; transient adequacy; V&V separation | verified quasi-static ≠ transient validation |
| D | I, IV, IX | exact-source applicability; proof branch/input provenance | primary value ≠ applicable proof |
| E | V, VI, VII | parent–child interface; FEA decision use | high local fidelity ≠ high input confidence |
| F | VI | independent cross-check and common-mode error | model agreement ≠ validation |
| G | VII | sensitivity, uncertainty, robustness envelope | robust in chosen envelope ≠ globally robust |
| H | VIII, IX | evidence-channel roles; remaining-life boundary | no defect observed ≠ life demonstrated |
| I | V, VI, VII, VIII | competing-method harmonization and discriminating evidence | disagreement ≠ one method wrong |
| J | I–IX | full expert synthesis; stop rules; authority handoff | analysis stop ≠ operation permission |

## Coverage invariants

Across A–J the learner must demonstrate all of the following at least once:

1. decision-question / claim-class framing before method selection;
2. as-found / approved / calculation configuration separation;
3. explicit boundary conditions and requested-output definition;
4. decision-driving input provenance and unknown register;
5. source/method applicability rather than source-prestige ranking;
6. smallest-adequate model selection;
7. source-bound proof stop when exact branch/input applicability is not demonstrated;
8. parent/child model-interface discipline;
9. verification / cross-check / validation separation;
10. common-mode error challenge;
11. sensitivity and uncertainty tied to decision change;
12. scenario-envelope provenance before robustness claim;
13. competing-method harmonization rather than blind averaging/ranking;
14. inspection / monitoring / classification / proof roles kept distinct;
15. remaining-life, discard and specialist-NDT boundaries preserved;
16. bounded technical conclusion and explicit request for missing evidence;
17. equipment-specific authority handoff;
18. explicit distinction between analysis stop and operational permission;
19. full integrated transfer in Case J.

## Claim locks

The following remain intentionally absent:

- reconstruction of closed paid tables, coefficients or branch logic;
- actual proof-of-competence result for a real crane component;
- unsourced dynamic/load-combination factors;
- numeric remaining-life / fatigue-life verdict;
- equipment-specific acceptance/discard decision;
- specialist NDT interpretation;
- permission to operate, repair, reroute, redesign or modify a real lifting appliance.

## Separation from Practice Reasoning

`CRN-M-02_D4_PRACTICE_v1.md` contains prompts, evidence fragments, conflicts and adversarial traps only.

The next stage — `D4 PRACTICE REASONING / v1` — may show multiple acceptable reasoning paths, evidence requests, V&V plans, model-comparison logic and bounded conclusions. It must not rewrite Practice into one deterministic answer key.
