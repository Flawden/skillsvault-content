# Findings and corrections

## RX-01 — Correct guards competed for working memory
**Severity:** HIGH

Added a five-question memory card:

```text
WHAT DRIVE / BOUNDARY?
→ WHERE DOES ROTATION / TORQUE GO?
→ WHAT FUNCTION DOES EACH COMPONENT HAVE?
→ WHAT IS OBSERVED VS ASSUMED?
→ WHAT EXACT SOURCE HAS SCOPE?
```

A missing answer routes to bounded STOP instead of guessing.

## RX-02 — The drive-path algorithm needed a reusable representation format
**Severity:** HIGH

Added a four-field recording template:

```text
OBJECT
→ LINK / INTERFACE
→ FUNCTION
→ KNOWLEDGE STATUS
```

The existing micro-case was rewritten into `ВИЖУ / МОГУ СКАЗАТЬ / НЕ МОГУ ПОВЫСИТЬ ДО` lanes so the learner can see how observation becomes a bounded D1 conclusion without becoming exact architecture, rating or acceptance.

## RX-03 — Reducer-family recognition was prose-heavy
**Severity:** MEDIUM

Added a compact geometry-first reducer-family router for cylindrical, bevel/combined, planetary and worm candidates.

The router explicitly says `candidate`: recognition still does not prove exact identity, selection, rating or suitability.

## RX-04 — Coupling guards were distributed across several sections
**Severity:** HIGH

Added a four-question coupling card:

```text
EXACT IDENTITY
→ FUNCTION
→ ALLOWED MOVEMENT TYPE
→ LIMIT / SOURCE
```

D1 may recognize function/family candidate, but exact identity, displacement limits, rating and mounting requirements remain source/OEM-bound.

## RX-05 — Source roles looked like nine document entries to memorize
**Severity:** HIGH

Added a question-first source-role map before the detailed source subsections.

The map begins from the technical question and exact object, then routes to vocabulary, general reducer scope, gear-coupling scope, formal rating, damage terminology, lubricant specification or actual equipment/OEM/regulatory authority.

No source hierarchy or applicability rule was changed.

## RX-06 — STOP semantics were technically correct but too dense for rapid recall
**Severity:** HIGH

Added a four-step compact STOP card:

```text
STOP UNSUPPORTED INFERENCE
→ NAME MISSING EVIDENCE
→ REQUEST EXACT DEVICE / SOURCE / OEM DATA
→ HAND OFF TO APPLICABLE PROCESS
```

The detailed STOP list remains in place and `SkillsVault STOP ≠ equipment-operation authority` remains explicit.

## RX-07 — The lesson ending still pointed backward to Technical Editorial
**Severity:** MEDIUM

Rebuilt the end-of-lesson retrieval layer:

- added a six-step `60-second retrieval spine`;
- reduced the retrieval checkpoint to seven grouped questions;
- explicitly marked it as **not formal Practice** and not an answer key;
- corrected the stale handoff so the lesson now points to `CRN-M-04 / D1 PRACTICE / v1`.

# Guard preservation

Reader Experience Pass I does **not** alter:

```text
VISIBLE / ASSUMED DRIVE PATH ≠ PROVEN COMPLETE ARCHITECTURE
RATIO + MOTOR NAMEPLATE ≠ ACTUAL TRANSMITTED TORQUE / PERMISSIBLE RATING
FAMILY / APPEARANCE ≠ EXACT COMPONENT IDENTITY / STANDARD APPLICABILITY
FLEXIBLE / COMPENSATING COUPLING ≠ MISALIGNMENT PERMISSION
LUBRICANT SPECIFICATION ≠ PROOF OF ACTUAL INSTALLED LUBRICANT / SUBSTITUTION AUTHORITY
DAMAGE NOMENCLATURE ≠ ROOT CAUSE / SEVERITY / ACCEPTANCE
NO OBSERVED SYMPTOM ≠ PROOF OF HEALTH
AGREEING EVIDENCE LANES ≠ INDEPENDENT CAUSAL PROOF
SOURCE TITLE / CATEGORY MATCH ≠ EXACT APPLICABILITY
SKILLSVAULT STOP / HANDOFF ≠ EQUIPMENT OPERATION COMMAND
```

Still locked:

- ISO 6336 design/rating calculations and coefficients;
- reducer/coupling selection and service factors;
- numeric alignment/displacement/backlash/wear/vibration/noise/temperature limits;
- lubricant selection/substitution/fill/change instructions;
- diagnosis from visible condition alone;
- inspection/acceptance/discard verdicts;
- repair/adjustment/overhaul instructions;
- continued-operation / return-to-service authority.
