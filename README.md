# SkillsVault Content

Публичный Git-репозиторий контентной части SkillsVault.

## Главный принцип

Этот репозиторий — **источник истины для учебного контента**, а не архив чатов.

Любой новый рабочий сеанс должен начинаться с:

1. `status/CONTENT_STATUS.json`
2. `ROADMAP.md`
3. активного Topic/Depth
4. последнего завершённого gate

## Текущая точка

`CRN-M-01 — Канаты и цепи`

- D1 — FROZEN v1
- D2 — FROZEN v1
- D3 — FROZEN v1
- D4 — ACTIVE, G1–G7 complete, G8 next

## Правило frozen content

Каталог `FROZEN_vN` никогда не редактируется.

Если материал нужно улучшить:

```text
CHANGE REQUEST
→ новая версия
→ повторный audit / alignment / red team
→ FROZEN_v(N+1)
```

## Что не хранить публично

Не добавлять:
- токены, пароли, ключи;
- персональные данные;
- внутренние документы предприятия без разрешения;
- чужие платные стандарты/PDF целиком;
- proprietary OEM-документы, если нет права на публикацию.

В репозитории хранятся наши учебные материалы, source notes, ссылки, методические выводы и созданные артефакты.

## Быстрый старт нового чата

Передайте ChatGPT URL репозитория и напишите:

> Открой `status/CONTENT_STATUS.json`, восстанови ROADMAP и продолжай с `next`.

Для публичного репозитория этого достаточно как постоянной точки входа.
